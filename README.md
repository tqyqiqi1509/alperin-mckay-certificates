# Alperin--McKay computation packages

The current package for **The Alperin--McKay conjecture**, revised 16 November 2026, is in [packages/am-2026-11-16](packages/am-2026-11-16/README.md). Its [calculation index](packages/am-2026-11-16/INDEX.md) maps the manuscript computations to source programs. Run its own `verify.py` to verify that package.

Earlier materials and the two companion-manuscript supplements remain available in their original locations; see [the legacy readme](README.txt). The root `MANIFEST.json` and `verify_manifest.py` describe that earlier distribution, not the new package.
